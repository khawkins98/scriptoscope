## One shared geometry primitive, two retained consumers

Expose the existing typed eight-piece cinf border plan from `engine/qd/cinfFrame.ts`. Its inputs need only source width/height, corner size, side thickness, tile flag, and destination Rect; it must not require pixels, resource lookup, a fabricated full cinf, browser objects or diagnostics. Its ordered outputs identify piece, source Rect, destination Rect, exact scalar source/destination extents, and the existing engine fast-path classification. The scalar and Rect representations have different floating-point operation order obligations under BG12; neither may be reconstructed from the other when that would change arithmetic. Narrow structural input types may replace broad types; avoid an address-named API. Keep the implementation in its existing file and preserve its engine calculation/order exactly.

All three engine consumers stay on that same plan: `prepareCinfFrameSamples`, `drawCinfFrame` border preparation/painting, and the bevel border composer. The bevel consumer retains its scalar compatibility normalization and empty/out-of-bounds suppression before executing existing transfer loops. Remove its duplicate eight-piece rectangle array and redundant source-clamped extents in the same batch. Bevel consumes the exact scalar sizes supplied by the shared plan; it does not subtract Rect endpoints to recover sizes. Do not replace the bevel transfer loop with engine tile/line transfer: geometry reuse does not establish those operations as interchangeable for every caller PNG.

## Questions outside this slice

Native bevel state selection/contradictory state precedence, metadata/provider search ownership, mono/device state, typography/transfer and unsupported native outcomes require a separately established family contract before a full migration. Source-backed qd geometry alone does not resolve them. There is no need to settle those unknowns or obtain native captures to preserve the chosen compatibility behavior. If exact geometry or trace equivalence cannot be retained for an input, stop on that item and return a behavior-only question to PM; do not broaden this batch.
