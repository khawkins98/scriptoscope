# Original-reference research records

For maintainers, spec writers and independent verifiers. Runtime implementers
must use their [brief](../spec/engine/IMPLEMENTER-BRIEF.md) and assigned safe spec;
this collection does not expand their allowed reading scope.

Directories below retain dated observations, capture conditions, follow-ups and
reproduction records. Read each record's declared inputs, scope and unresolved
limits before citing it. A captured or matching image does not establish full
historical rendering fidelity. Do not rewrite observations as current usage docs
or pool results from different conditions.

For a new acquisition, use the [maintainer reference environment](../maintainer-reference-environment.md)
and the role-gated [spec index](../spec/README.md). Consumer behavior belongs in
[interaction](../interaction.md) or [integration](../integration-edge-cases.md).
