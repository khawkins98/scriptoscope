# Halcyon in real Kaleidoscope 2.3.1

Screenshots of `../scheme.bin` loaded in the original Kaleidoscope 2.3.1
control panel on System 7.5.5. They were taken in the maintainers' private
reference emulator (Basilisk II, 8 bpp, sound off; see
[`docs/maintainer-reference-environment.md`](../../../../docs/maintainer-reference-environment.md))
on 2026-10-30, in one boot with no errors.

| File | What it shows |
|---|---|
| `finder-windows@2x.png` | an active Finder window over an inactive one, plus a floating window |
| `control-panel@2x.png` | the Kaleidoscope control panel with Halcyon selected (name and version read from its `vers`) |
| `alert-default-ring.png` | a stock alert with Halcyon's teal default-button ring |
| `windowshade.png` | a window-shaded (collapsed) window over inactive windows |

A control run with the corpus Windows 95 scheme, installed the same way,
behaved the same, so the install procedure isn't what made Halcyon work.

These are illustrations that the generated file is a valid scheme. They are
**not** admitted fidelity evidence (no reference-intake review, 8 bpp palette
condition), and no golden or ledger row depends on them. The `@2x` files are
nearest-neighbour upscales of the native 640×480 frame.
