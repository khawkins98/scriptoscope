# Authored schemes

Start with the [authoring guide](../docs/authoring-a-scheme.md) and
[brief template](./concept-brief-template.md). Kingfisher is the worked reference
implementation, separate from the community corpus in `themes/`; corpus
rendering gates do not cover authored schemes. Scheme checks discover new
directories automatically.

```sh
npm run author -- authoring/schemes/kingfisher
npm run check:schemes
npm run dev
# /authoring-preview.html?scheme=/authoring/schemes/kingfisher/scheme.rsrc
```

| Path in `schemes/<slug>/` | Purpose |
|---|---|
| `scheme.mjs` and optional family modules | `buildScheme()` returns the resource list |
| `palette.mjs` | Named procedural colours; extracted illustrations may keep source-derived palettes |
| `concept/` | Brief, selected image and saved prompt; extraction recipes when needed |
| `sprites/` or `parts/sprites/` | Editable 1× PNGs; geometry and repeats stay in code |
| `scheme.rsrc` | Committed raw fork; tests reject stale generated bytes |
| `scheme.bin` | Generated, untracked MacBinary for classic transfer |
| `meta.json` | Identity, author and license metadata |
| `preview.png`, `preview-sizes.png` | Current browser review captures |
| `classic/` | Native captures and exact-build validation record |

Apply hidden colour swatches after importing PNGs, and reject accidental
semi-transparent alpha. Copying an example's source does not transfer its review
or VM proof. Update identity and credits, regenerate previews and validate your
own final bytes.

Kingfisher demonstrates imported illustrations, frame recipes and control-family
builders. `preview-layouts/` holds HTML fragments for `?layout=`, including the
narrow/wide stress layout.
