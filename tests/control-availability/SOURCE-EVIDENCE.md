# Source evidence boundaries

The finite availability expectations distinguish archive facts, our public API
policy and an original-engine dispatch observation. Shared decoders extract the
archive facts; that is not independent verification of decoding.

## Default-ring state dispatch

The original Kaleidoscope 2.3.1 `kDEF` 0 68k resource is 107726 bytes, SHA-256
`2c027276dae2355964a0dde1ace31f60ba845ab2c5fbf0496fd34ab2afe7c342`.
Extraction is documented in `docs/spec/kdef-binary-inventory.md`; the standing
interpretation is `docs/spec/kdef231-reference.md`, ring entry `0x76c4`.

The narrower pressed-ring fallback range is **0x76d2–0x76fe**. At 0x76d2 the
pressed/mixed byte at `a2+9` is tested. The nonzero path requests signed ID
-10230 at 0x76de and calls the ring painter at 0x76e2. The result is tested at
0x76e8; a successful result branches away at 0x76ec. Otherwise the path requests
-10231 at 0x76f4 and calls the painter at 0x76f8, ending its stack cleanup at
0x76fe. This supports the finite missing-pressed-ring→active-ring expectation.
It does not prove a complete historical control rendering algorithm.

The resource hash and these addresses were checked against the locally
extracted disassembly without executing the original engine. The original
binary/disassembly are not shipped in the repository or CI. Automated checks
validate the pinned reference documents and declared engine identity; they do
not reauthenticate the original binary in CI.

## Author labels and key policy

Animals and Monkey Paradise label cicn -10239 `Solo Menu Background`; their
same-ID cinf is labelled `Push Button`. These labels establish names, not an
authoritative original dispatch role. The former label-rejection/pressed substitution was a modern compatibility
policy, corrected by the numeric dispatch evidence below.

Manifest keys are a separate public bundle naming policy. Unnamed source art
uses the signed raw-ID key; these named sources use normalized author labels.
The finite expectations pin exact keys independently of runtime traces. Two
resources with the same signed metadata under competing keys are not treated
as interchangeable. Source fork/payload hashes are independently pinned input
evidence, but the initial trace exposes no actual decoder fork/payload identity.

## Canonical push-face dispatch (2026-10-19)

At 0x7576 the disabled byte selects -10240 at 0x757c; otherwise the pressed
byte at 0x7582 selects -10238 at 0x7588. The remaining path loads -10239 at
0x758e, pushes that signed ID at 0x7592 and calls the face helper at 0x7594.
No author-name test intervenes. Thus an available exact negative state ID
precedes friendly names in the modern resolver. Base-chain ordering, named
aliases, positive-ID aliases and missing-state fallbacks remain compatibility
policies; this correction does not authenticate original resource providers
or establish whole-control pixel fidelity. The same pinned engine identity
and static-analysis limits above apply.
