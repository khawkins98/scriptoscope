# Explicit page host

`explicit-host.mjs` is application example code, separate from package exports.
Use the [hosted reference](../docs/hosted-reference.md) for source selection,
options, handle methods, failure policies and ownership. Use
[decorate a page](../docs/decorate-a-page.md) for working recipes.
