04 / HEADERS
Bounded support

          
A surface and a set of columns.

          
Whole-header surfaces draw a rectangle without labels. The separate column helper adds labels and per-cell sizing as a compatibility policy. Neither API adds sorting or column-resize interaction.

          

          
Try a different clipping context
The whole-surface API needs a known clip declaration. An unknown clip returns an explicit unsupported result.

Missing art means unavailable. An unsupported result means this request is outside the admitted subset; it does not mean the scheme lacks all header resources. Unknown clipping, special window origins and some source bodies/sampling remain outside the supported surface.

05 / MENUS & CURSORS
Partial / absent

          
Know the edges before you build.

          
The public Platinum helpers draw menu bars, dropdown panels and closed popup faces. These procedural appearance samples do not change with the scheme and have no menu interaction, command dispatch or scheme-resource selection.

          

          
Scheme mouse cursors: no public API
The runtime uses ordinary browser cursors for pointer and resize affordances. There is no public API here to decode, select or install a scheme cursor. Menu-like resources in a theme catalog do not establish an interactive menu implementation either.

          
Reproduce procedural menu samples
bufferToCanvas(platinumMenuBar({ titles: ['File', 'Edit', 'View'], activeIdx: 0, width: 280 }))
bufferToCanvas(platinumMenu({ items: ['New', 'Open…', '-', 'Close'], highlightIdx: 1, width: 140 }))
bufferToCanvas(platinumPopupMenu({ label: 'Choose a view', minWidth: 160 }))

Theme loading and advanced integration boundaries
loadTheme loads a bundle URL; loadKaleidoscopeScheme accepts archive bytes. createThemeResolver caches loads; dispose after the last consumer. attachThemeDropZone and registerTheme connect local files to an existing mount. This page uses standalone themes with no injected base scheme, so base inheritance cannot hide a missing resource.
prepareDisplayProfile accepts validated caller-supplied display tables. This page uses the loader’s default display policy and does not fabricate an indexed-device profile. Preparing a profile, a CINF environment or CICN transfers is an advanced data path, not a one-click emulation mode.
